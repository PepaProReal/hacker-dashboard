> HACKING MODUL

1. IP vs MAC (Navigace)

IP (Logická): Adresa bytu. Může se měnit. Proč: Potřebuji vědět, kde jsem. Cíl: z veřejného internetu do soukromé sítě.
MAC (Fyzická): Rodné číslo/otisk prstu. Trik: MAC Spoofing (obejdu filtry, vydávám se za autorizovaného).

IP (Logical): Home address. Can change. Why: Need to know where I am. Goal: from public to private network.
MAC (Physical): ID number/fingerprint. Trick: MAC Spoofing (bypass filters, pretend to be authorized).

2. IPv4 vs. IPv6 (Příležitost)

IPv4: Staré, adresy došly. IPv6: Nekonečno adres. Příležitost: Nikdo to neumí zabezpečit, tam jsou peníze.

IPv4: Old, addresses ran out. IPv6: Infinite addresses. Opportunity: Nobody knows how to secure it, that's where the money is.

3. Hacking jako LEGO

Znám dílky (IP, MAC, protokoly) = postavím exploit. Neznám = kopíruju návody a skončím.

Know pieces (IP, MAC, protocols) = build exploit. Don't know = copy tutorials and fail.

4. Research (CVE & PoC)

CVE: Rodný list chyby. PoC: Důkaz chyby (pozor na malware!). MAN pages: Bible Linuxu.

CVE: Vulnerability birth certificate. PoC: Vulnerability proof (watch for malware!). MAN pages: Linux Bible.
