> HACKING MODUL

1. IP vs MAC (Navigace)

IP: Logická (adresa bytu). Může se měnit. MAC: Fyzická (otisk prstu). Trik: MAC Spoofing (vydávám se za autorizovaného).

IP: Logical (home address). Can change. MAC: Physical (fingerprint). Trick: MAC Spoofing (pretend to be authorized).

2. IPv4 vs. IPv6 (Příležitost)

IPv4: Staré. IPv6: Nekonečno adres. Příležitost: Slabé zabezpečení = šance pro hackery.

IPv4: Old. IPv6: Infinite addresses. Opportunity: Weak security = chance for hackers.

3. Hacking jako LEGO

Znám dílky (IP, MAC, protokoly) = postavím exploit. Neznám = kopíruju a skončím.

Know the pieces (IP, MAC, protocols) = build exploit. Don't know = copy tutorials and fail.

4. Research (CVE & PoC)

CVE: ID chyby. PoC: Důkaz (pozor na malware!). MAN pages: Linux Bible.

CVE: Vulnerability ID. PoC: Vulnerability proof (watch out for malware!). MAN pages: Linux Bible.

> LINUX POWER COMMANDS

cd - Change Directory
cat - Read content (concatenate)
pwd - Print Working Directory
find -name "file" - Search for files
grep "text" file - Search text inside file
grep -R "text" - Recursive search
wc -l - Count lines
man - Manual (Linux Bible)
